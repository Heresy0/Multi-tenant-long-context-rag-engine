# 业务文档与合成语料说明分离

2026年10月5日清理星海部门版 v3 的30份业务文件，以及仍在技术库中的旧版API手册、维护通知副本。公司、客户、人员、事件和业务数值仍是合成设定，不能因正文删去测试说明而宣称为真实企业数据。

## 清理边界

语料来源声明集中放在文档包README和manifest，二者不上传业务知识库。删除统一的“虚构测试资料”“企业RAG测试语料”“不具有实际管理或法律效力”等语料说明，以及嵌在业务段落中的同类测试标记。版本有效期、历史归档提醒、合同示范文本的签约限制、沙箱只能使用模拟或脱敏数据、API示例地址密钥提醒均保留。

这不是通用入库清洗规则。不能在解析器中全局删除“虚构”“测试”“法律效力”，否则可能改变真实合同、安全规范或业务结论。这里仅使用审核后的语料专用白名单，并保存原文件、原哈希和逐字符内容对照。

## 文件处理

`scripts/clean_xinghai_business_documents.py` 离线生成候选副本，不调用模型或自动修改数据库。原生PDF真正删除对应文字，不用白色覆盖来隐藏仍可检索的文本；必要的业务段落局部重新排版。扫描件只删除测试说明区域，保留图片型PDF，不注入答案文本层。Word仅移除指定说明段落，不改标题表格结构。本环境无可用的Word分页渲染工具，用户已同意人工Word排版验收，不能声称通过自动分页验收。

PDF编辑依赖PyMuPDF和fonttools，仅安装在任务临时目录，不增加后端生产依赖。文档作者操作使用应用提供的文档Python运行时。

## 评估与入库

文档内容变动后同步manifest、上传清单、压缩包、扫描原文对照和评估题集源哈希。题集标注版本为`2026-10-05-r4`；60道单轮、8组24轮多轮、12项权限题保持不变，答案和评分标准不放宽。组织规模题的来源短语只由“模拟规模180人”改为“规模180人”。历史报告保留，不将旧答案重打分当作新模型复测。

扫描件哈希改变后，必须重新对照原图和真实OCR输出，再新增对应哈希的人工更正记录。旧哈希记录保留；更正只覆盖负责人字段，整页OCR仍保持待核查标志。

在线替换使用既有候选上传和持久化索引任务。保留文档ID、source_id、知识库、存储位置和创建者，内容版本递增，向量与关键词索引一起重建。索引失败由现有候选文件恢复流程保留旧文件并支持重试。文档替换本身不修改用户或部门授权，不删除旧评估报告。管理操作前保存数据库备份和原文件，之后核对ready状态、哈希、大小、版本、切片、关键词与向量一致性及无关文档未变化。
